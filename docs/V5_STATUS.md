# Aegis Nexus V5

V5 is being rebuilt from the V4 codebase with a strict separation between verified backend intelligence and simulation.

## Current foundation

- Dedicated `v5-rebuild` branch
- Canonical intelligence event types
- Central V5 Zustand store
- Event normalization boundary
- Realtime EventSource client with reconnect behavior
- V5 command-center surface at `/v5`
- Explicit runtime modes: LIVE, DEGRADED, CONNECTING, OFFLINE, SIMULATED, ERROR
- Runtime health endpoint
- No fabricated threat score is generated by the V5 surface

## Next implementation layers

1. Replace the V4 simulated SSE route with a real backend gateway.
2. Add a canonical backend event envelope and provenance metadata.
3. Connect ingestion -> normalization -> classification -> correlation -> intelligence events.
4. Replace deterministic/fake embeddings with a provider-backed embedding interface.
5. Unify model routing behind one provider abstraction.
6. Restore the intelligence API modules referenced by the existing service entrypoint.
7. Connect agents to real event jobs and persist their outputs.
8. Add database adapters for relational, vector, and graph storage.
9. Add WebSocket/SSE fan-out from the backend.
10. Expand the V5 command center with map, agent operations, timeline, network, reports, missions, SIGINT, economy, and review surfaces backed by the same event model.
11. Add automated type-check, unit, integration, and end-to-end validation.

## Non-negotiable V5 rule

A source failure must never silently become fake intelligence. If simulation is enabled for development, the UI must label the runtime as `SIMULATED` and preserve the provenance of simulated events.
